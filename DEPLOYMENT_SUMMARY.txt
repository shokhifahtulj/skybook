🚀 DEPLOYMENT IN 3 STEPS:

  STEP 1: Generate APP_KEY (5 minutes)
  ─────────────────────────────────────
  $ php artisan key:generate --show
  
  Copy the base64:... output
  Save it - you'll need it in Step 2


  STEP 2: Set Railway Environment Variables (3 minutes)
  ──────────────────────────────────────────────────
  In Railway Dashboard → Project Settings → Variables:
  
  • APP_NAME=SkyBook
  • APP_ENV=production
  • APP_KEY=base64:...  (from Step 1)
  • APP_DEBUG=false
  • DB_HOST, DB_PASSWORD, etc. (auto-populated if linked)
  
  See .env.production for complete list


  STEP 3: Deploy (2 minutes)
  ──────────────────────────
  $ git add .
  $ git commit -m "Fix: Production-ready Railway deployment"
  $ git push railway main
  
  Then monitor: $ railway logs --follow
  
  Verify: $ curl https://skybook.railway.app/up
